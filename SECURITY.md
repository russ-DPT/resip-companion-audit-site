# Security and data protection

- This repository, the public audit site and its demo contain no participant
  data. The demo analyses only data it simulates itself.
  Never commit an audit bundle from a real study, and never attach one to an
  issue or pull request.
- Real study data are analysed only inside ReSIP, after data collection
  closes, under the roles approved by the IRB. Only the Research Advisor can
  download an audit bundle.
- Report a security or data-protection concern privately to
  research@resip.science rather than opening a public issue.
